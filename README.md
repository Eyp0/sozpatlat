# 🧠 SozPatlat - Laf Sokmanın İncelikli Hâli

**sozpatlat.ninja**; laf sokmak, imalı konuşmak ya da yaratıcı cümlelerle zihin açmak isteyenler için hazırlanmış bir mini web projesidir. Eğlenceli, sade ve kullanıcı dostu bir yapıya sahiptir.

## 🚀 Özellikler

- 💬 Hazır sözlerle otomatik "laf sokma" deneyimi  
- 🎲 Rastgele söz gösterimi  
- 📱 Mobil uyumlu modern tasarım  
- ⚡ Hızlı ve veritabanı gerektirmeyen yapı  
- 🌐 Hem `www.sozpatlat.ninja` hem de `sozpatlat.ninja` adresinden erişim

## 🛠️ Kullanılan Teknolojiler

- HTML5 & CSS3  
- JavaScript (Vanilla)  
- (İsteğe bağlı: TailwindCSS / Bootstrap gibi framework varsa buraya eklenebilir)
